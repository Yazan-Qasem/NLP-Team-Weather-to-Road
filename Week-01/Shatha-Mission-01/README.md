# 🖥️ مهام الطالب - الأسبوع الأول (1/11 - 14/11) [غير مكتمل]
### التخصص: هيكل الواجهة والخريطة الافتراضية (Mock UI Layout)



- 
مهمة الطالب الرابع (مطور الواجهة والخريطة التفاعلية - UI & Dashboard)

الهدف: تحويل بيانات التنبؤات التي جهزتها أنت إلى لوحة تحكم تفاعلية تعرض خريطة نيويورك والشوارع المهددة بالإغلاق.
• الأدوات المطلوبة: لغة Python مع مكتبات Streamlit و Folium (أو streamlit-folium) و Pandas.
• المدخلات (من مجلدك): ملف final_nyc_road_closures_predictions.csv (الذي يحتوي على أسماء الشوارع، حالتها CLOSED أو CAUTION، وسبب الخطر، والإحداثيات the_geom).

خطوات التنفيذ المطلوبة منه:

1. بناء واجهة الموقع (app.py): تصميم صفحة رئيسية باستخدام Streamlit تحتوي على عنوان المشروع وبطاقات إحصائية سريعة في الأعلى (مثل: إجمالي الشوارع المغلقة، إجمالي الشوارع تحت التحذير، ونوع العاصفة المتوقعة).
2. إضافة الفلاتر الجانبية (Sidebar Filters): وضع قائمة جانبية تتيح للمستخدم تصفية النتائج حسب:
	• المنطقة في نيويورك (Borough): (Manhattan, Brooklyn, Queens, Bronx, Staten Island).
	• حالة الطريق (Status): (مغلق CLOSED أو حذر CAUTION).
	• المدى الزمني التنبؤي: شريط تمرير (Slider) لعرض التوقعات خلال الـ 24 أو 48 ساعة القادمة.
3. رسم الخريطة التفاعلية (Folium Map):
	• عرض خريطة مدينة نيويورك في منتصف الشاشة.
	• قراءة الإحداثيات من عمود the_geom في ملف الـ CSV ورسم نقاط أو خطوط الشوارع على الخريطة.
	• تلوين الشوارع حسب حالتها: اللون الأحمر للشوارع المصنفة CLOSED، واللون البرتقالي/الأصفر للشوارع المصنفة CAUTION.
	• إضافة نافذة منبثقة (Popup) عند الضغط على أي شارع تظهر اسمه، حالته، وسبب الإغلاق المتوقع (Flood أو Snow/Ice).
4. عرض جدول البيانات: وضع جدول تفاعلي أسفل الخريطة يعرض قائمة الشوارع المهددة مع إمكانية البحث فيها.

- [ .] إسقاط خريطة رقمية لمدينة نيويورك داخل الموقع باستخدام مكتبات الخرائط (Folium / Mapbox).
- [. ] وضع نقاط وإحداثيات وهمية ملونة على الخريطة (Mock Markers) لاختبار كفاءة العرض والتفاعل دون انتظار البيانات الحقيقية من السيرفر.
